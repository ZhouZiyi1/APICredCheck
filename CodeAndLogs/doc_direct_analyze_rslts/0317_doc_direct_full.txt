3. Integration requirement: There is no usual setup in which the developer must obtain a vendor-issued key, app ID, token, or similar credential from Nacho Lopez to use this SDK. Standard Android permissions and platform/service dependencies may be required, but those are not vendor console-issued API credentials for this product.

4. Scope: Any separate credentials a developer might need for other services (for example, unrelated Google APIs in a broader app architecture) are not credentials for this SDK itself. For the Smart Location Library's documented integration, no product-specific vendor credential appears required.
