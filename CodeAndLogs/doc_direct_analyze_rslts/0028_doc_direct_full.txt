SECTION 1: Detailed Analysis

1. Android support — Yes. Firebase Performance Monitoring has official Android support via the Firebase Android SDK.

2. Service model — It is not purely on-device. The SDK collects app performance traces, network request metrics, and related telemetry, then sends that data to Firebase’s hosted backend for aggregation and display in the Firebase console. So normal use relies on vendor-hosted services.

3. Integration requirement — Yes. Standard Android integration for Firebase services requires registering the Android app in the Firebase console and adding the Firebase config file to the app. For Android, this is typically the `google-services.json` file, which contains identifiers such as the Firebase App ID / project configuration used by the SDK to connect to Firebase backend services.

4. Scope — This credential/config is part of the documented integration for Firebase Performance Monitoring on Android, not merely an optional separate product. Performance Monitoring is a Firebase product and uses the app’s Firebase project/app configuration for its backend connectivity.
