SECTION 1: Detailed Analysis

1. **Android support** - Yes. Amazon Chime SDK has an official Android SDK/library for integrating audio/video calling and meeting features into Android apps.

2. **Service model** - It routinely relies on vendor-hosted services as part of normal use. The SDK is a client for Amazon Chime meeting/media services rather than a purely on-device utility library.

3. **Integration requirement** - For normal integration, the Android app uses meeting/session configuration generated by a backend that calls AWS/Amazon Chime service APIs. However, the mobile SDK itself is not typically configured with a console-issued app credential such as an API key, App ID, or client secret embedded in the app. Standard usage is to create meetings/attendees server-side with AWS credentials, then pass session data to the app.

4. **Scope** - The relevant credentials are AWS credentials used by the developer's backend to call Amazon Chime/AWS APIs, not an Android app credential specifically issued for the Amazon Chime SDK itself. Since the prompt asks whether the app must obtain and configure a vendor-issued credential in the app for this SDK, the answer is no.
