SECTION 1: Detailed Analysis

1. Android support  
Sumsub provides an official Android Mobile SDK and Android integration documentation for its identity verification flow. Android is supported.

2. Service model  
This product is not primarily on-device. Sumsub’s SDK is a client for a vendor-hosted identity verification/KYC service: applicant data, document capture, checks, and verification session handling are tied to Sumsub’s backend APIs.

3. Integration requirement  
Typical Android integration requires passing a Sumsub SDK access token into the SDK to launch the verification flow. That token is normally generated by the developer’s backend using vendor-issued credentials from Sumsub (commonly an app token and secret key in Sumsub’s platform). So standard use depends on vendor-issued credentials and a token-based setup to access Sumsub-hosted services.

4. Scope  
This credential requirement belongs to Sumsub itself, not a separate third-party product. The Android SDK’s normal documented flow depends on a Sumsub-issued token/credential chain for the verification session. Evidence for Android support and token-based integration is strong.
