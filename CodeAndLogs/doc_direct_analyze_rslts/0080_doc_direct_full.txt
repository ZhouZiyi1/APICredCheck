SECTION 1: Detailed Analysis

1. Android support — Yes. Pangle SDK is ByteDance’s mobile advertising SDK and has official Android integration/documentation for app developers.

2. Service model — It routinely relies on ByteDance-hosted ad services. In normal use, the SDK requests, fills, and measures ads via the vendor’s remote backend; this is not a purely on-device library.

3. Integration requirement — Yes. Standard Android integration for Pangle requires registering the app in the Pangle/ByteDance developer console and configuring console-issued identifiers in the app. The typical required value is an App ID for SDK initialization, and ad serving also uses placement/ad unit identifiers. Under the prompt’s definition, this qualifies as an API credential because it is a vendor-issued identifier required for the SDK to access the vendor-hosted advertising service.

4. Scope — This credential is part of Pangle SDK’s own documented integration flow, not a separate product. The App ID is specific to using Pangle’s ad platform on Android.
