SECTION 1: Detailed Analysis

1. **Android support** - Yes. Insider provides an official Android/mobile SDK and Android integration documentation for its customer engagement/growth platform.

2. **Service model** - This SDK is not just an on-device helper. Its normal use is to connect the app to Insider’s hosted engagement/personalization services for analytics, push, in-app messaging, journeys, and related campaign features. That indicates routine reliance on vendor-hosted backend services.

3. **Integration requirement** - Yes. Standard Insider mobile SDK setup requires app-specific identifiers issued by Insider so the SDK can associate the app with the correct Insider account/environment. The commonly documented required value is an **Insider Partner Name** (sometimes paired in setup with app group/environment-style values depending on platform/features), which is a vendor-provided integration identifier rather than merely package/signing metadata.

4. **Scope** - This credential is part of Insider SDK’s own documented integration flow, not only a separate third-party service added alongside it. Because the SDK’s standard features depend on Insider-hosted services, this app/account identifier qualifies as an API credential under the definition given.
