SECTION 1: Detailed Analysis

1. **Android support** — Yes. Google Mobile Ads SDK (AdMob) has an official Android SDK and documented Android integration via Google’s Android developer documentation.

2. **Service model** — This SDK routinely relies on Google-hosted ad services as part of its standard function. It loads and serves ads from Google’s ad backend, so it is not a purely on-device library.

3. **Integration requirement** — Yes. Standard Android integration requires configuring an **AdMob App ID** in the Android app manifest. Developers also use **ad unit IDs** to request ads. Of these, the clearest console-issued app-level integration credential required by the SDK setup is the **App ID**.

4. **Scope** — This credential is part of the documented integration for this specific product (Google Mobile Ads SDK / AdMob), not merely another Google product. The AdMob App ID is specifically used to initialize and identify the app for the ads SDK.
