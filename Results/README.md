# Results

This directory contains two summarized result spreadsheets for APICredCheck.

- `doc_direct_summary.xlsx`: SDK Screening results for the top 1,000 SDKs.
  This file summarizes whether each SDK supports Android and whether it is identified as involving API credentials.

- `validation_rslt.xlsx`: validation results for the top 50 SDKs.
  This file summarizes the full experimental results for the top-50 SDK study, including SDK Screening outcomes, Legitimate App Analysis results, Runtime Validation results, and manual inspection results.
